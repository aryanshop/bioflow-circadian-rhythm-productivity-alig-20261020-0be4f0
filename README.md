# BioFlow: Circadian Rhythm & Productivity Aligner

BioFlow is an interactive productivity and wellness tool designed to help remote workers, professionals, and students align their daily work schedules with their natural circadian rhythms and biological peak energy windows.

## Features

- **Chronotype Customization**: Configure your biological profile (Lion, Bear, Wolf, Dolphin) and target wake-up time.
- **Interactive 24-Hour Circadian Timeline**: Visual canvas rendering energy wave fluctuations across the day with a dynamic interactive time scrubber.
- **Task Energy Matcher**: Add custom tasks with varying cognitive requirements (High Focus, Steady Work, Low Admin) and instantly discover their ideal execution slot.
- **Phase Breakdown**: Detailed guidance on optimal windows for deep work, afternoon slumps, and melatonin wind-down.

## Local Run Instructions

1. Download or clone all project files (`index.html`, `style.css`, `script.js`, `README.md`) into a single folder.
2. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
3. No installation, server, or build steps required.

## Technology Stack

- Pure Vanilla HTML5, CSS3 (with CSS Variables & Glassmorphism UI), and Modern JavaScript (ES6+).
- HTML5 Canvas for real-time circadian wave rendering.
- 100% Client-side static application with zero external dependencies or network requests.
